# CLAUDE.md

## Project
Capstone project for the FlyRank Front-End AI Engineering track.

## Stack
- HTML, CSS, JavaScript
- Node.js (LTS)
- Git and GitHub

## Conventions
- Use semantic HTML.
- Use `const` and `let`, never `var`.
- Keep CSS in separate files, not inline.
- Keep functions small and give things clear names.
- Never commit `.env` files or secrets.

## Git
- Commit messages use Conventional Commits: `type: short description`
- Types: feat, fix, docs, style, refactor, test, chore
- Write the description in lowercase, no period at the end.
- One change per commit.
